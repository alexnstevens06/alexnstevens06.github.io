# LucidScan — Chrome extension prototype

**Hook:** LucidScan is a Chrome extension prototype, grown from a TIDALHack 25 project, that adds local-score badges to images and selected text on sites you enable. It runs open models (TMR text detector, CLIP ViT-B/32) entirely in your browser; the score is a signal, not an authenticity verdict.

## What it is

LucidScan is a Chrome extension prototype, grown from a TIDALHack 25 project, that adds local-score badges to images and selected text on sites you enable. It runs open models (TMR text detector, CLIP ViT-B/32) entirely in your browser; the score is a signal, not an authenticity verdict.
