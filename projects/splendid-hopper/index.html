Projects / splendid-hopper

splendid-hopper

A small C++20 Vulkan engine: ASCII-filtered roguelike prototype plus an animated torus live-wallpaper.

What it is

Weekend / antigravity graphics work. rogue_vulkan is an SDL2 + Vulkan executable with a simple player/enemy/particle loop and an ASCII post filter. Separately, torus mesh shaders drive wallpaper-style demos recorded as mp4/webp.

No public GitHub remote (local tree only).

My role

Sole author of engine and game code under src/engine and src/game.

Tech

C++20, Vulkan, SDL2, CMake, GLSL → SPIR-V.
